# Restart-Free dnsmasq DNS Switching + 50ms Handshake Poll — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the ~3.3s `/etc/init.d/dnsmasq restart` from the VPN connect path (and the matching outage at disconnect) by switching dnsmasq upstreams through an inotify-watched managed resolv-file, and drop the exit-handshake poll from 500ms to 50ms — cutting router time-to-Connected from ~6.4s to ~2.5–3s.

**Architecture:** A daemon-lifetime **single-writer actor** owns the managed file `/tmp/resolv.conf.d/nym-resolv.conf` (always a regular file; all updates are write-temp + `rename(2)` in the same tmpfs dir). At startup it converges system state idempotently: targeted staged-uci repoint of `dhcp.@dnsmasq[0].resolvfile` (never committed), committed-store accident repair, seed from `resolv.conf.auto`, and a *conditional* dnsmasq restart only when the running instance's generated config doesn't already point at the managed file. Connect/disconnect become file renames + a cache-flush SIGHUP delivered to the ubus-discovered ujail wrapper PID. While disconnected, a 5s tick inside the same actor mirrors netifd's `resolv.conf.auto` into the managed file (serialized with connect writes by construction — no TOCTOU). The per-connect `Dnsmasq` structs in `nym-dns` become thin clients of the actor.

**Tech Stack:** Rust (tokio mpsc/oneshot actor), BusyBox/uci/ubus shell-outs, OpenWrt procd/ujail, dnsmasq 2.93 (inotify build).

## Global Constraints

- Commits in repo style (`feat(dns): …`, `perf(wg): …`, `fix(ipk): …`); **NEVER any Claude/AI attribution or Co-Authored-By trailers** (hard project rule).
- **Never `uci commit`** our own staging; the only permitted commit is the one-time *repair* that deletes an accidentally-committed `resolvfile` pointing at our managed file.
- **Never `uci revert dhcp` wholesale** — targeted per-option reverts only (`noresolv`, `server`, `resolvfile`), so user-staged dhcp edits survive.
- Managed file must live **inside `/tmp/resolv.conf.d/`** (ujail bind-mounts that directory; anywhere else is invisible to jailed dnsmasq).
- Managed file is **always a regular file, never a symlink** (dnsmasq inotify resolves the watch name once at startup; symlink swaps are verified invisible — tests T8b/T8d, 2026-07-19).
- SIGHUP is **cache-flush only** (verified: with polling on, SIGHUP does NOT re-read resolv files); reload is carried entirely by dnsmasq's inotify. Never signal via the dnsmasq pidfile — it contains the in-jail PID (`1`). Discover the PID via `ubus call service list '{"name":"dnsmasq"}'` (returns the ujail wrapper PID; HUP forwarding verified).
- The exit-handshake wait stays advisory/never-fatal, WG-only, cancel-safe, 10s cap.
- Keep `prefer_ipv4_upstreams` (v4-only-when-available) and its unit tests verbatim.
- Do not touch: probe timings in `nym-connection-monitor`, kill-switch/firewall code, registration path.
- An administratively-stopped dnsmasq stays stopped: converge logs loudly and skips the restart.
- Keep an info-level `Configured dnsmasq` log line in the connect path (hardware benchmarks time `Setting DNS servers` → `Configured dnsmasq`).

/// Minimal extraction of the instance pid from `ubus call service list` output.
/// Deliberately not a JSON parser: the shape is stable procd output and we
/// only need one integer; a serde dependency isn't warranted.
fn extract_instance_pid(service_json: &str, section: &str) -> Option<u32> {
    let inst = service_json.find(&format!("\"{}\"", section))?;
    let rest = &service_json[inst..];
    let pid_key = rest.find("\"pid\"")?;
    let after = &rest[pid_key + 5..];
    let digits: String = after
        .chars()
        .skip_while(|c| !c.is_ascii_digit())
        .take_while(|c| c.is_ascii_digit())
        .collect();
    digits.parse().ok()
}

```rust
trait Sys: Send + 'static {
    fn uci_revert_option(&self, key: &str);                    // best-effort, logs on failure
    fn uci_set(&self, key: &str, value: &str) -> Result<()>;   // staged only
    fn repair_committed_resolvfile(&self) -> Result<()>;       // uci delete + uci commit dhcp (the ONE allowed commit)
    fn committed_dhcp(&self) -> String;                        // contents of /etc/config/dhcp ("" if unreadable)
    fn dnsmasq_section(&self) -> Option<String>;               // e.g. "cfg01411c" from `uci show dhcp`
    fn generated_conf(&self, section: &str) -> Option<String>; // /var/etc/dnsmasq.conf.<section>
    fn restart_dnsmasq(&self) -> Result<()>;
    fn service_json(&self) -> String;                          // `ubus call service list '{"name":"dnsmasq"}'`
    fn send_hup(&self, pid: u32);                              // libc::kill(pid, SIGHUP), log on error
}
struct RealSys;
fn converge<S: Sys>(sys: &S, managed_file: &str) -> Result<ConvergeOutcome>;
enum ConvergeOutcome { Ready, DnsmasqStopped }  // Stopped = configured but service intentionally down
```

**Converge algorithm (implement exactly this order):**
1. Targeted reverts: `uci_revert_option` for `dhcp.@dnsmasq[0].noresolv`, `.server`, `.resolvfile` (clears legacy ≤1.31 scheme and our own stale delta; user's other staged dhcp edits untouched).
2. Committed repair: if `committed_has_managed_path(sys.committed_dhcp())` → `sys.repair_committed_resolvfile()` + `tracing::warn!` (LuCI Save&Apply persisted our staged delta; deleting the option restores stock-default behavior).
3. `sys.uci_set("dhcp.@dnsmasq[0].resolvfile", managed_file)?` (staged, never committed → reboot auto-reverts).
4. Section discovery: `sys.dnsmasq_section()`; `None` → error (`NoDnsmasq`).
5. If `sys.extract… / service_json` shows no running instance for the section → log `warn!("dnsmasq is not running; leaving it stopped")`, return `DnsmasqStopped` (do NOT start it).
6. If `generated_conf(section)` already `generated_conf_points_at(managed)` → return `Ready` **without restart** (kills the watchdog-crashloop restart storm).
7. Else `sys.restart_dnsmasq()?`, then re-read `generated_conf` and assert it points at managed; on mismatch retry steps 3–7 once (third-party restart raced us), then error loudly (this is the DNS-leak race guard).

impl Dnsmasq {
    pub fn new() -> Result<Self>;                       // OpenWrt+uci detection, get-or-spawn global actor
    pub async fn set_dns(&mut self, servers: &[IpAddr]) -> Result<()>;
    pub async fn reset(&mut self) -> Result<()>;
}
enum Cmd {
    SetTunnel(Vec<IpAddr>, tokio::sync::oneshot::Sender<Result<()>>),
    SetWanMirror(tokio::sync::oneshot::Sender<Result<()>>),
}
enum Mode { Tunnel, WanMirror }

**Actor semantics (the review's condition 1 — single writer by construction):**
- On spawn: run `converge` (retry lazily on first command if it failed); seed managed file from `wan` (missing → header-only file); `Mode::WanMirror`.
- `SetTunnel`: `write_managed(render_resolv_conf(&prefer_ipv4_upstreams(servers)))` via temp+rename → re-assert `generated_conf_points_at` (cheap self-heal; on mismatch re-run converge — catches third-party restarts that raced a stale config in) → HUP (cache flush, best-effort, failure = warn not error) → `Mode::Tunnel` → ack. Log `info!("Configured dnsmasq with VPN DNS servers: {:?}")` (benchmark marker).
- `SetWanMirror`: copy `wan` contents (missing → header-only) via temp+rename → HUP → `Mode::WanMirror` → ack.
- 5s `tokio::time::interval` tick: only in `Mode::WanMirror`, read `wan`, compare with current managed content, rename-write **only if different**, NO HUP (cache flush on background mirror would churn LAN caches). A tick arriving in `Mode::Tunnel` does nothing — the TOCTOU leak path is structurally impossible because ticks and commands are serialized in one `select!` loop.
- Actor is global: `static ACTOR: OnceLock<mpsc::Sender<Cmd>>`; `Dnsmasq::new()` keeps the existing `/etc/openwrt_release` + `uci get dhcp.@dnsmasq[0]` detection, then `get_or_init` spawns `run_actor(RealSys, real_paths(), rx)` via `tokio::spawn` (callers are inside the daemon runtime).
- **Delete** from the old implementation: `BACKUP_MARKER`, `RESOLV_CONF`/`RESOLV_CONF_BACKUP` + `write_resolv_conf`/`save_backup`/`do_reset` (conditions 3 & 6: converge IS recovery; the init script's `localuse=0` branch points `/tmp/resolv.conf` at `127.0.0.1` so local programs ride dnsmasq — do not fight it), `uci_revert("dhcp")` wholesale, unconditional `restart_dnsmasq` on set/reset, `uci_add_list`/`uci_delete` server-list plumbing.
